# 规范标题、作者和单位

## 必要输入

- 前序候选或既有 MD、item.json、原文题头位置及译名。
- 读取[交接约定](../literature-zotero2obsidian/references/pipeline-contract.md)；涉及项目路径、模板、工具或阻断级别时读取[项目配置](../literature-zotero2obsidian/references/project-profile.md)。

## 执行步骤

1. 对照选定版本的题头和可靠元数据。
2. 依次排原题、适用的译名、作者和单位。
3. 整理原文位于单位后的元信息。

## 约束

- 原文与条目不一致时保留证据，不跨版本拼凑。
- 完整原题用原生 H1，不用截断文件名。
- 外文题名的中译紧接下一行；中文原题不生成同义译名。
- 题名区与作者之间留一个空行。
- 作者与单位之间留一个空行。
- 采用默认对齐，不加 HTML 包装。
- 作者姓名照录原文并转义字面字符。
- 所属单位名称照录原文并转义字面字符。
- 作者顺序依原文，作者间用分号。
- 作者邮箱写作 `[姓名](mailto:…)`，只用本篇对应邮箱。
- 单位编号与通讯星号用行内 LaTeX 上标，如 `${}^{1,\ast}$`。
- 单位行用对应编号起首，如 `${}^{1}$`。
- 多个单位逐行列出，以行尾两个空格硬换行。
- 无证据不增标记；旧标记缺证时保留并记待核。
- 不另立通讯作者行或开头引文行。
- 单位后的 DOI、日期、版权、基金、通讯说明或地址及引用格式逐行放入同一 `> ` 引用块。
- 元信息块内不空行，块前后各一空行。
- 原文没有元信息时省略该块。
- 摘要交正文处理，关键词交属性步骤。
- 单位未核实与原文未提供分别记录。

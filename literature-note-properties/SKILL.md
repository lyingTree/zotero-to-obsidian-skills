# 构建笔记属性

## 必要输入

- item.json、对应类型模板、content_input 或既有笔记。
- 读取[交接约定](../literature-zotero2obsidian/references/pipeline-contract.md)；涉及项目路径、模板、工具或阻断级别时读取[项目配置](../literature-zotero2obsidian/references/project-profile.md)。

## 执行步骤

1. 读取实际 itemType 对应模板。
2. 仅编辑起始 YAML 属性区。

## 约束

- 新建管理键限 `类型`、`年份`、`关键词`；期刊论文另用 `期刊名`。
- `库内参考文献` 是废弃键。新建禁用，修复时删除整键及其值，包括空值。其值是否曾人工填写不影响删除。库内出链保存在参考文献条目中。
- 不新增索引、路径、哈希或运行状态字段。
- 上述废弃键除外，保留未知自定义键和人工值；冲突记录双方来源。
- 年份与命名所用版本一致，取整数或空值。
- 关键词用列表，来源限可追溯原文或条目字段。
- 未知值按模板类型留空、null 或省略。
- 含 `: `、` #` 或结尾为 `:` 的字符串加引号；其他值保留原写法。

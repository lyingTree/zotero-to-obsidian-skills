# 按术语表翻译

## 必要输入

- item.json、source.md、source-map.json、术语表。
- 读取[交接约定](../literature-zotero2obsidian/references/pipeline-contract.md)；涉及项目路径、模板、工具或阻断级别时读取[项目配置](../literature-zotero2obsidian/references/project-profile.md)。

## 执行步骤

1. 核实语种，确定应译块。
2. 按章节或语义段翻译，保留块 ID 与上下文。
3. 核对译块与原文的对应关系。

## 约束

- zh 复用 source.md，外文题名或摘要不触发整篇重译。
- non-zh 翻译正文、题注、表头、注释等应译文本。
- mixed 优先复用已有完整中文对应块并记录映射。
- unknown 或判断冲突时交第 1 步复核。
- 术语表记录路径与哈希；缺失时译稿标待核。
- 同义概念依语境统一用词；多义词逐处判断。
- 重叠上下文只输出一次。
- 保留论证顺序、否定、条件、因果强度和不确定性。
- 模式、反演、作者推断保留原有证据性质。
- 不添加解释或结论。
- 数值、单位、符号、公式、对象 ID、编号、DOI 及 URL 与原文对应。
- 人名和所属单位照录原文。
- 作者—年份引文中的 `et al.` 和双作者间的 `and` 按原文照录，分别禁止译为“等”和“和”。中文文献中原引文已写作“等”或“和”时照录。原刊使用 `&` 等其他连接形式时同样照录。
- 表格只译文本，保持单元格值与合并关系。
- 图内文字保留原样。
- 编号公式引用统一为「公式3b」等形式，保留前缀、后缀与范围；方程术语依原义翻译。
- 外文题名另产中文译名，保留完整原题。
- 书目保留发表时原文，包括中文条目，不附加题名中译。
- 未收录术语记原词、拟译、语境及待核原因，不自动修改共享术语表。
- 原文疑误及 OCR 歧义附定位回核，不猜补数值或定义。
- 必要译注独立写为 `> 译注：…`。

## 产物

- run.json.content_input、terminology.json；需要翻译时生成 translated.md。

## 验收标准

- [ ] 全部应译块均有对应译块或未译原因。
- [ ] 逐段复核歧义、否定和结论强度，注明实际范围。
- [ ] 数值差异已区分月份、二维/2-D、Unicode 上下标等表示变化。
- [ ] 术语、单位、公式和引文标签已核对。
- [ ] 未决术语与原文疑点已登记。

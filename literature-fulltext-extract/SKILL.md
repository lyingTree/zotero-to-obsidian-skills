# 提取全文与段落

## 必要输入

- item.json 已确认的主全文及附件哈希。
- 读取[交接约定](../literature-zotero2obsidian/references/pipeline-contract.md)；涉及项目路径、模板、工具或阻断级别时读取[项目配置](../literature-zotero2obsidian/references/project-profile.md)。

## 执行步骤

1. 核对附件身份、版本与哈希，探测解析器。
2. 按阅读顺序提取正文、列表、脚注、题注、图表、公式、附录及书目。
3. 逐块登记稳定 ID、来源位置及覆盖决定。

## 约束

- PDF 先检查文本层乱码、缺字、空白与串栏，仅对问题页或区域按对应语言 OCR。
- DOCX/ODT 保留段落、表图和公式关系。
- HTML/EPUB 按文档阅读顺序解析。
- TXT/MD 核对编码。
- 图像序列按已核实的页序 OCR。
- 旧 DOC/RTF 先验证转换结果。
- 按文字坐标和方向辨别分栏、侧栏、跨栏题注与旋转文字，避免固定裁框截字。
- 侧栏要点、作者贡献与致谢须保留。
- 页眉页脚或页码仅在确认是重复版面元素后移除；人工页码留在来源映射。
- 仅合并同段版面断行；跨页先核对衔接。
- 保留英文词间空格，删除中文无意义空格。
- 区分断词、复合词、负号与范围连字符。
- 段落之间留空行；列表、表格、数学和代码保持独立。
- 按悬挂缩进重建书目，逐条保留原文。
- 跨块分式和上下标对照源页重建。
- 低质量 OCR 逐处核对数值、单位和公式；不确定处保留候选与定位。
- PDF 图像按[裁剪与验收规则](references/figure-crop.md)逐图提取。图框以内保留完整图件，题注单独保存。
- 图像保留实际编码和扩展名；二进制另存，JSON 只记路径与哈希。
- 表格保留行列、合并、单位与注释；复杂表另存结构与核对图。
- 公式保留原号并核实 LaTeX。
- 主全文与 SI 按附件角色分工，SI 交第 11 步。
- 保留原件与原始解析结果；后续步骤使用候选稿。

## 验收标准

- [ ] 每页或章节均有覆盖记录，排除与失败有定位和原因。
- [ ] 未解释的漏页、重复段和串栏均已处理或列为未决。
- [ ] 每个图、表、公式、脚注及书目条目可回溯至源文。
- [ ] PDF 图像逐幅通过[裁剪视觉验收](references/figure-crop.md)，记录源页、裁剪范围及证据。
- [ ] 正文语言与原判断冲突时已反馈第 1 步。
- [ ] 关键内容不可辨时保留工作稿并标记阻断。

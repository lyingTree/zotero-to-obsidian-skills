# PDF 图像裁剪与验收

1. 按图号定位原附件、PDF 页和题注，结合原页渲染判定实际图框。优先提取完整原图；图由多个对象组成时，按图框高分辨率渲染或裁剪。文本坐标只辅助定位。
2. 逐图保留全部子图、面板号、图内文字、轴线、刻度、单位、图例、色标等，并留少量安全边距。排除图外题注、邻图、正文、页眉页脚、页码和大块页边空白。原题注单独保存。整页截图只可作为取证材料；图占满可见页面时仍按实际图框验收并记录依据。跨页图按面板顺序登记各页裁剪范围。
3. 逐图并排查看原页和实际将嵌入的图片，先看全图，再放大检查边缘与细小文字。核对面板齐全、图内要素可读、无页内容混入、图号和题注对应。仅凭资源存在、可加载、能解码、尺寸或锚点有效，不能判定裁剪通过。
4. 每幅记录来源附件与哈希、PDF 页码、图框坐标及坐标系或原图对象定位、输出路径与哈希、视觉验收结论和证据位置。复用图按同一标准核验。最终嵌入图必须与已验资源一致；有缺裁、多裁、错图或图框不确定时先修复并复验，未通过的图阻断对应提交。

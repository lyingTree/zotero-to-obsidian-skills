# Hu 2024 技能修订后的独立复测协议

## 目标与版本

本轮在九配置基线试验后继续完善通用技能。先独立执行 Sol low；如果发现失败，修订通用流程后以新版本、新目录重新执行，不修补原候选并改判。Sol low 首次完整通过后，优先独立重复确认，并在同一冻结版本执行 Terra 的 low、medium、high。目标配置为 Terra medium；目标不等于已取得的结果。

实际模型 ID 沿用基线：Sol 为 gpt-6.2-sol，Terra 为 gpt-6.1-terra。Luna 基线结果仍属于原版本；未在新版本执行的配置明确标为 not_tested。不同版本的结果不拼成同一完成矩阵。

每次启动前提交并冻结实际技能树，由运行清单绑定完整 Git SHA、技能文件哈希、任务哈希及输入哈希。若冻结后发现代码缺陷，原试次仍归属其原版本；修复采用新冻结版本。

## 输入与执行独立性

输入继续使用用户提供的正文 PDF、补充 DOCX。标准 Markdown 只用于评审，翻译等价与源文疑点例外沿用九配置基线协议。

执行任务使用 model_matrix.py 中同一 TASK，不附本轮发现、修正提示、预期对象数、标准译文、之前候选或具体通过答案。代理使用 fork_turns=none，显式指定模型与推理强度。每次创建独立目录；仅将冻结技能与两份原始输入交给执行者。不得读取其他试次、标准稿或评审材料，不联网取同篇译稿，不创建子代理。

使用原生 DOCX、逐块产出和确定性格式工具属于所有输入可使用的通用技能能力。不得把本文译文、数字、题注或专用图片坐标写入技能。

## 评审与修订

沿用 2026-11-24-hu2024-protocol.md 的单目标验收、来源优先与文件层范围。新静态检查只提供格式和结构证据，不自动给出语义通过。

每次完成后冻结完整 work/output，核对来源、技能与任务未被修改。独立评审分别核查文本语义与信息、数值单位与公式、表格、图片题注、书目和调用、结构与资源绑定。一个决定性必需目标失败可判本次失败；判通过则必须完成全部适用必需目标，不以片段齐全、清单勾选或零语法错误代替。

若需要继续开发，只把可推广的问题转为下一版技能改动。旧运行目录与结论保持原样。不得在当前执行者收到具体缺陷提示后，将修正稿作为无指导独立通过。执行者在原任务内自行发现并修正的问题计入该次最终表现。

## 中断与重复

宿主中断、工具错误与模型正常结束但质量不足分别记录。原上下文的后续消息只用于明确记录的恢复，不改称新独立试次。需要真正重复确认时重新创建代理和目录。

一次通过仅代表这一篇、该次执行。至少独立重复通过后才能报告本材料上的重复成功；仍不能据此估计跨论文稳定成功率。任何失败或未核对目标如实保留，不由目标配置反推结果。

## 交付

公开仓库保存通用改动、虚构材料回归、协议与摘要。原始来源、标准稿、模型候选和图片仅进入私有交付。记录真实调用回执、冻结哈希、逐目标评审、执行续接与代码验证结果。宿主未提供的 token、费用和精确推理耗时不估造。

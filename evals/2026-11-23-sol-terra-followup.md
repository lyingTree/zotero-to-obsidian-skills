# Sol / low 与 Terra 分档复测

本轮目标是先使 `gpt-6.2-sol / low` 通过已知材料的完整离线验收，再在同一冻结技能版本上比较 `gpt-6.1-terra` 的 low、medium、high。Terra / medium 预先要求两次独立执行均通过。模型名称、推理强度、试次与版本分别记录；一次通过不表示对所有文献的成功率。

PR #1 保持 Draft，未合并。当前正在修订和复测，尚未建立达到目标的模型门槛。

## 输入与隔离

每个新执行代理只收到冻结的文献技能、模板、术语表和两份原始 PDF。验收样例、历史候选、评分、已知缺陷与配置比较结果不进入执行目录。执行代理不创建其他代理，主控不补写候选。所有试次保留，失败不被成功重试覆盖。

独立审阅按正文与译义、身份与公式书目、图表与格式分工。审阅者获得候选原件和来源证据，不获得模型配置清单。首轮说明文件包含总体模型测试顺序，因此不能声称该轮完全不可推断配置；后续审阅说明已移除模型名称与执行次序。

真实 Zotero 与 Obsidian 环境本轮没有提供。离线内容、执行过程和真实应用行为分别判定。

## v02 通用修订

- 补齐独立来源的通讯说明盘点及题头映射。
- 保留来源网址的可见文字，并验证实际链接目标。
- 增加同图多面板调用、标题间距、末尾分隔线、图内表锚、中文时长、范围连字符及公式尾标点的定向提示。
- 排除代码、数学环境、隐藏注释及链接目标中的伪正文。
- 精确保留 PDF 文字层中的 CR、CRLF 和 LF；换行归一化后重新绑定哈希仍不能冒充原始提取证据。
- 术语台账绑定实际术语表，分别记录已收录和未收录术语的采用依据。
- 每幅图生成独立的待填视觉检查，显式记录来源坐标系、源页和最终图件。
- 从实际技能文件生成逐验收 ID 台账；全量规则目录与待填验收集合分开，默认不会产生通过结论。
- 图台账绑定不可覆盖的库存快照；辅助台账指针变化不会破坏已核对记录，来源内容变化仍会被检出。

## 后续判定

v02 推送后的干净 CI 环境发现 Pillow 未列入正式运行时依赖，Windows 另暴露测试中长路径与短路径的字符串断言问题。对应运行 [45125808041](https://github.com/lyingTree/zotero-to-obsidian-skills/actions/runs/45125808041) 的失败记录保留。已启动的 v02 执行在候选内容尚未被评审前中止，部分工作及哈希保存，不计入成功或失败。修订正式依赖清单后包指纹发生变化，因此重新冻结 v03 并从新代理开始；不在执行中的快照中补文件。路径测试改为比较解析后的实际路径，语义标准不变。

新版本使用全新代理从原始 PDF 重新执行。只有 Sol / low 的适用离线目标全部有证据通过，才启动 Terra 三档；Terra / medium 的重复执行使用同一版本。任何影响行为的修订都重新冻结版本，并重测关键配置。最终报告分别列出原始输出、内容结果、过程待验和真实应用阻断，不把离线通过描述为真实应用端到端无问题。

用户的 PDF、验收样例、完整候选和图件不随公开仓库提交。完整来源与审阅证据另行保存。

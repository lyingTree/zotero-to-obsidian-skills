# 确定性 Python 辅助层与九份原稿重放

## 开发方向

按用户要求，由明确指定的 `gpt-6.2-astra` 实现并交叉审查通用 Python 层。模型提交内容单元与译文，程序负责结构组装、规范化、机械验收、版本保存和按环节报告。

新入口见 [工作流说明](../literature-zotero2obsidian/references/deterministic-pipeline.md)和[可编辑运行脚本](../literature-zotero2obsidian/references/process_note_example.py)。

| 模块 | 确定性职责 |
|---|---|
| `render_note.py` | 由来源计划与翻译槽位组装题头、标题、列表、图表、公式、书目、链接与SI；拒绝缺项或越权覆盖。 |
| `normalize_note.py` | 无损处理明确格式；保护已有标题身份、代码、链接目标、正确公式和结构化数据；记录可重放变换。 |
| `accept_note.py` | 读取实际文件与资源；独立验收也报告仍需安全格式修复的具体位置；同时核对对象、链接、来源合同、映射及哈希。 |
| `note_pipeline.py` | 冻结准备任务、统一处理、真实幂等检查、原子写入、断点恢复、并发和变更检测；输出中文阶段报告。 |

程序不能自动证明译义、原图裁剪内容或来源清单完整。未知输入保留并定位；没有宣称任意输入都能完美处理。

## 验证

本地完整回归 **856 项通过**。程序交叉审查保留了修复前后反例，包括伪图计数、表格代码上下文、标题链接断开、图编号误并入百分比、冷启动并发和验收后源文件变化。

新代码已统一处理历史九稿，并再次完整重跑核对一致性。原稿、工作文件和资源的冻结哈希保持不变。数字串、引用目标与编辑回放不变量逐份验证；这些检查不替代语义评审。
